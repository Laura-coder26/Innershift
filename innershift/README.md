# Innershift 🌱
### Sito di crescita personale

**URL live:** https://innershift.vercel.app

---

## Struttura del progetto

```
innershift/
├── index.html          → Homepage pubblica
├── css/
│   ├── style.css       → Stile homepage
│   └── admin.css       → Stile dashboard admin
├── js/
│   ├── main.js         → Funzionalità homepage
│   └── admin.js        → CMS admin completo
├── admin/
│   └── index.html      → Dashboard amministratore
├── images/             → Immagini del sito
└── vercel.json         → Configurazione deploy
```

## Accesso admin

Vai su `/admin/index.html` e inserisci la password:

```
innershift2026
```

> ⚠️ Cambia la password nel file `js/admin.js` alla riga `const ADMIN_PASSWORD = 'innershift2026';`

## Funzionalità

- ✅ Homepage pubblica con articoli, eventi e risorse
- ✅ Dashboard admin con login
- ✅ Creazione e pubblicazione articoli
- ✅ Generazione sintesi automatica
- ✅ Condivisione social (LinkedIn, Facebook, X, Instagram)
- ✅ Calendario eventi e workshop
- ✅ Upload e gestione file
- ✅ SEO + Open Graph
- ✅ Design responsive mobile-first

## Deploy su Vercel

1. Carica questi file su GitHub
2. Vai su vercel.com
3. Importa il repository
4. Clicca Deploy — il sito è live!
